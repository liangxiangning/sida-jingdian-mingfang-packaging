五套风格，20 版设计

同一个系列骨架下，五种不同的“古方脸”。每行四款是同一风格，竖着看是同一产品换五种。横向比风格，纵向比一致性。四款并排的陈列图分别放在每一行的下沿，用来验证系列感。

市场风格收集：36 个同剂型对手

这是他们的画法全集：只留固体饮料——冲调粉、颗粒、条袋、罐装粉，口服液、植物饮、酵素饮、膏滋、OTC 颗粒全部剔除。这一节回答一件事：货架上的脸都长什么样。

筛法

淘宝按销量排序逐页筛，再按剂型逐条判定，只保留固体饮料类。

销量口径

只记页面当时显示的数字；“全店售 N 件”是整店累计，不与“N 人付款”横向比。

没数字的

页面未显示销量的写“未见数字”，不估算、不凑整；罐装与袋装都标注清楚。

03

五种市场语言，落成五套设计

36 个同剂型包装看下来，货架上其实只有四种说话方式；第五种（礼盒）没人做。我们把四种各做到位，再做一套没人做过的——五套不是五个备选，是五个位置的答案。

五套的来处

每一套都能在同剂型里找到出处
市场流派谁在用他们的共同语言对应我们哪一套
古方克制派 药小七、火星暖暖、菩茵堂、大道居参有 米白／浅粉／墨绿底、竖排品名、线描药材或花窗、几乎不写功效词 → A 汉方书卷：整套借骨架，最省事也最像“方”
药房权威派 埤盾、南京同仁堂、北京同仁堂（四川）、世宴 白底或深底、药业背书、法定声明压底、大份量装、字重厚 → B 药柜图谱：借“档案感”，把几味药变成看得见的标本卡
功效直给派 沐迎康、贝蓓臻护、吉亚多、马应龙小满醋 大字功效句、器官或月亮图形、撞色、模特与场景图 → C 现代配方：只借数据条与撞色，不借喊话式大字
极简白派 浣小亲、易仟天、成康雅贝、Ovilz、京华维康 白底 ＋ 单一图形 ＋ 英文副标，弱化食品感 → D 色彩版：走它的反面，用整片品牌色换三米识别
（市场空白） 36 个里没有一个礼盒装 — → E 礼盒版：没人做过，所以我们不借谁，自己做一套

三条看得见的事实

这是筛选之后才看得见的
34 / 36 是盒＋条袋形态几乎同质，货架上真正能分开的只剩“脸”：竖排还是横排、留白还是满版、写方名还是写功效。
会写方名的多，会摆方子的少用“方名＋独立条袋”讲古方的，只有埤盾、大道居、药小七三家；其余把“古方”当品类词用，主视觉交给图案和功效句。
四种语言，没有一种被两家做全古方派赢气质、药房派赢可信、功效派赢远距、白派赢干净。所以我们把五套分别做到位，而不是合成一张中庸的脸。

五套共用的四条底线

换风格，不换骨架
竖排四字品名，占盒高 18% 以上

A／C／D 都用这条；B 与 E 换成“品名独立成块”的读法，识别位置不变。

一个画面只出现一枚朱印

红只用在系列指纹这一处；到礼盒版它变成盒盖的封签，位置不变。

60 / 25 / 15 网格

主视觉六成、信息两成半、法定声明一成半。五套共用同一网格，换风格不用重排。

正面不写功效词

普通食品的红线：助眠、舒压、调理这类词不上正面。风格可以换，这条不换。

所以推荐这一套：A＋

用 A 打底，向 B 和 C 各借一件
A

骨架来自 A

米白纸面、单色墨线、竖排品名、朱印、信息带——最稳的一层，货架上立刻被认作“古方”。

B

借 B 的一块

每味药一张小标签牌（人参／茯苓／白扁豆……），把配方从“概念”变成“看得见的几味药”。

C

借 C 的一条

一条配方比例条，把“几味药、各多少”做成可读的数据——让“方”有据可查，而不是只有气质。

一句话一眼是古方，细看有依据。

请您定三件事

定了就能进生产稿

① 骨架走哪套

A 到 E 五套里挑，或 A＋。建议 A＋：A 的稳，配 B 的料和 C 的数据；D 留给线上主图，E 留给礼赠档。

② 四款主色认不认

暖赭脾胃、中绿咽喉、暖金深棕补气、深蓝助眠。一色一款，远看分得开。

③ 范围怎么排

四款一次做齐，还是先落 A＋ 打样，再决定 D（线上主图）与 E（礼赠档）各铺几款。

五套不是五选一，是五个位置：A 打底、B 讲可信、C 讲数据、D 抢三米、E 做礼赠。市场那 36 个包装证明，货架缺的不是“更国潮”，是把“方”讲清楚的那一张脸。
